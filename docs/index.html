The problem

Similarity search only reaches half the memory

Long-term memory lets a conversational agent stay coherent across sessions, follow through on commitments made weeks earlier, and adapt to each user. But today's LLM-backed memory is reachability-bounded by query–content similarity, lexical or dense. That works when a query and a memory share surface features such as wording or named entities — the descriptive regime. It misses an equally common regime where query and memory share no surface form and are tied only by a latent semantic arc — the associative regime. Prevailing memory systems collectively fail on this second half.

T-Mem covers both. At each of two evidence granularities — single facts (items) and full exchanges (scenes) — it instantiates one descriptive and one associative trigger family, so every memory stays reachable from surface-similar and relevance-bound queries. These write-time rehearsals — the engineering counterpart of episodic future thinking — are what we call triggers.

Contributions

What's new

01 · framing

A 2×2 recall space

Granularity (item / scene) × orientation (descriptive / associative). Prior memory systems occupy only the descriptive half.

02 · method

One trigger per quadrant

Entity & Scene cover the descriptive half; Bridge & Horizon cover the associative half that similarity search cannot reach.

03 · architecture

Triggers off the evidence path

How a memory is reached is decoupled from what is reached. Triggers guide retrieval only; scenes and items remain the evidence.

04 · results

State of the art, both benchmarks

80.26% on LoCoMo (+3.25 pp) and 74.81% on LoCoMo-Plus, collapsing the cross-benchmark gap to a single-digit margin.

Approach

Construct, then retrieve top-down

A four-stage write pipeline — scene segmentation, topic assignment, item extraction, trigger instantiation — builds a typed memory graph. At read time, a top-down topic → scene → item cascade fuses lexical and dense rankings with RRF, with associative triggers bypassing the topic prefilter so relevance-bound cues aren't gated by similarity.
